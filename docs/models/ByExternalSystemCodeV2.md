# com.pitneybowes.api360.Model.ByExternalSystemCodeV2
Defines shipment creation parameters based on an external system reference. When provided, the system automatically retrieves and applies carrier, service, and parcel details mapped to the specified external system code. <br/> For now, External System Codes supported only for carriers UPS, USPS and FedEx.
